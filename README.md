## Praktikum 4: Box Element
1. Persiapan Dokumen HTML Awal
   
   Mempersiapkan text editor (seperti VS Code) dan membuat file HTML dasar dengan nama lab4_box.html. Dokumen ini diisi dengan struktur kerangka standar HTML5 dan sebuah tag header bertuliskan "Box Element".

2. Membuat Box Element dengan Tag div
   
   Menambahkan elemen pembungkus section yang berisi tiga tag div di dalam dokumen HTML untuk merepresentasikan konsep Box Element. Ketiga elemen tersebut masing-masing diberi kelas div1, div2, dan div3
   <img width="1917" height="1013" alt="Screenshot 2026-10-13 210847" src="https://github.com/user-attachments/assets/9cd693bf-3af9-4113-a6fc-a17d7f1bc4d4" />


3. Menerapkan CSS Float Property
   
   Menambahkan kode CSS di dalam bagian <head> untuk mengatur elemen div agar menggunakan properti float: left serta memberikan padding. Selain itu, masing-masing kelas .div1, .div2, .div3 diberikan warna latar belakang yang berbeda (merah, kuning, hijau) untuk melihat efek kotak yang berjejer secara horizontal.
   <img width="1917" height="1012" alt="Screenshot 2026-10-13 210916" src="https://github.com/user-attachments/assets/f87cd296-b12e-4259-afea-3bdc39cee31e" />

4. Pengaturan Clearfix Element (Properti Clear)
   
   Menambahkan elemen div keempat div4 dengan latar belakang biru setelah div3 untuk menguji perilaku elemen setelah properti float. Selanjutnya, ditambahkan properti clear: left dan float: none pada kelas .div4 guna mengatur posisi elemen agar turun ke bawah secara teratur dan tidak bertumpuk dengan elemen float di atasnya.
